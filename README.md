# Release
Here you can find and download the latest available Project Reboot builds for supported platforms.
Project Reboot is a **free-to-play, unofficial fan project** based on Pixel Worlds, made to bring back the OG 2018 Pixel Worlds experience, with a twist!

## Available Platforms
- **Windows:** Download the `.zip` file from the corresponding platform folder and version folder, extract it, and launch the game.
- **Android:** Download the `.apk` file from the corresponding platform folder and version folder, then install it on your phone.

## Additional Information
- Project Reboot is **completely free to play**, with no in-app purchases.
- Some builds may contain bugs, unfinished features, or other issues.
